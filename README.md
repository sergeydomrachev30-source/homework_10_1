### Виджет банковских операций клиента

### Описание проекта

Этот проект представляет собой бэкенд-часть виджета для фильтрации и сортировки банковских операций клиента. Программа позволяет обрабатывать списки транзакций: фильтровать их по текущему статусу (например, выполненные, отменённые, в обработке) и упорядочивать по дате совершения операции. Разработка ведётся в соответствии со стандартами PEP 8 и методологией GitFlow.

### Инструкция по использованию и примеры работы

Все основные функции для обработки данных находятся в модуле src/processing.py. 

### 1. Фильтрация операций по статусу (filter_by_state)

Функция принимает список словарей с данными о транзакциях и возвращает новый список, содержащий только операции с указанным статусом (по умолчанию фильтрует по 'EXECUTED'). 

```python

from src.processing import filter_by_state

data = [
    {'id': 1, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 2, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}
]

# Фильтрация по умолчанию (EXECUTED)
executed_data = filter_by_state(data)
print(executed_data)
# Вывод: [{'id': 1, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}]
```

### 2. Сортировка операций по дате (sort_by_date)

Функция принимает список словарей и сортирует их по ключу date. По умолчанию сортировка производится по убыванию (от самых свежих к самым старым операциям). 

```python

from src.processing import sort_by_date

data = [
    {'id': 2, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 1, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}
]

# Сортировка по умолчанию (по убыванию дат)
sorted_data = sort_by_date(data)
print(sorted_data)
# Вывод: сначала элемент с датой 2019 года, затем 2018 года
```
